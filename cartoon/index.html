什么是 Harness？

模型权重之外的一切工程基础设施
🧠 通俗理解
大模型是一匹烈马，Harness 就是驾驭它的缰绳
🐎 ⭐ ✨
Harness 不是让模型更聪明，而是让模型 更懂得工作

💡 OpenSpec 管流程，TDD 管质量

4 步搭建专属 Harness

1

初始化 OpenSpec

openspec init，建立规范驱动流程框架

2

引入 TDD Spec Schema

每个变更自动生成测试用例结构，将“测试先行”固化为 AI 不可跳过的流程节点

3

注入项目专属 Skill

├── 术语管理：术语表 → 指令子系统
└── 知识管理：架构决策和踩坑记录 → 状态子系统
4

启动第一个变更

/opsx:propose → apply → archive
propose 展开：proposal → specs → design → tasks
